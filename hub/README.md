# hub

## 階層

- `inc/`
  - 読み込み・PHP処理
- `admin/`
  - 管理画面用 CSS / JS / PHP
- `pages/`
  - frontpage / fudousan / iezukuri のCSS・JS
- `css/`
  - `hub.css` だけ legacy として残す

## 禁止

- 外側の `frontpage/`, `fudousan/`, `iezukuri/` は使わない
- `hub/common/` は使わない
- `hub/css/admin/` は使わない
- `hub/css/` に新規CSSを追加しない
